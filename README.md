# Rafsan Raiyan — Portfolio

Personal portfolio of **Rafsan Raiyan** — Full-Stack Web Developer & E-Commerce Specialist based in Dhaka, Bangladesh. Available on-site and remote worldwide.

A single, self-contained `index.html` — no build step, no dependencies. All CSS and JavaScript are inline; project screens are hand-drawn SVG. Light and dark themes, scroll-linked animations, and a responsive layout.

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Any static host works (GitHub Pages, Netlify, Vercel, Cloudflare Pages) — just publish the repository root.

> Before going live, replace the placeholder domain `https://rafsanraiyan.com/` in `index.html` (canonical + Open Graph tags), `robots.txt`, and `sitemap.xml` with the real URL.
